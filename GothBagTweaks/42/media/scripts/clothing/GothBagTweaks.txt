       TombAlternative.Bag_L_Loose / Bag_L_Tight (大型哥特风背包) so that they get:

         2) CanHaveHoles = true (Legendary Backpack has no such line at all; Tomb's
            original said false, which opted the bag OUT of holes)
         3) AttachmentsProvided = the same slot set the Legendary Backpack uses

       Everything else is copied verbatim from
       3616536783\mods\Tomb's Wardrobe - Alternative - Vanilla\42.20\media\scripts\clothing\tomb_containers.txt
       (the duplicate "EquipSound = EquipSatchel" line was dropped; the effective
        value EquipSound = EquipBackpackSmall is kept).

       mod.info has require=TombWardrobeALTVanilla so this file loads AFTER the
       original and replaces both item scripts. If Tomb's mod is ever updated and
       changes these blocks, re-sync this file.
       ============================================================================ */
